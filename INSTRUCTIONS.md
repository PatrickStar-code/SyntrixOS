O projeto utiliza Next.js no frontend e Node.js no backend.

Sua tarefa é implementar as funcionalidades pendentes seguindo rigorosamente o fluxo abaixo:

Processo para cada funcionalidade

1. Criar branch

Antes de qualquer alteração, crie uma nova branch utilizando um nome descritivo baseado na funcionalidade.

Exemplo:

feature/cadastro-usuarios
feature/agendamento-consultas
feature/dashboard-relatorios 2. Análise e planejamento

Antes de escrever qualquer código:

Analise a funcionalidade solicitada.
Identifique arquivos que serão alterados.
Identifique possíveis impactos no sistema.
Defina uma estratégia de implementação.
Apresente um plano detalhado contendo:
Objetivo da funcionalidade.
Arquivos que serão criados ou modificados.
Etapas da implementação.
Possíveis riscos ou dependências.

Pare após apresentar o plano e aguarde minha aprovação antes de continuar.

3. Implementação

Após minha aprovação:

Implemente a funcionalidade seguindo as boas práticas do projeto.
Mantenha o código limpo e consistente com a arquitetura existente.
Reutilize componentes e serviços já existentes sempre que possível.
Explique brevemente as alterações realizadas.

Ao finalizar a implementação, pare e aguarde minha análise antes de prosseguir.

4. Testes

Após minha aprovação:

Crie testes automatizados utilizando Vitest.
Cubra:
Casos de sucesso.
Casos de erro.
Casos de borda relevantes.
Execute os testes.
Apresente o resultado da execução.

Pare após os testes e aguarde minha validação.

5. Commit

Após minha aprovação:

Verifique se todos os testes estão passando.
Faça o commit seguindo o padrão:
feat:nome-da-feature

Exemplo:

feat: cadastro-usuarios
feat: agendamento-consultas

Apresente a mensagem de commit antes de executá-la.

Aguarde minha aprovação.

6. Push

Após minha aprovação:

Execute o push da branch para o repositório remoto.
Informe exatamente qual comando foi utilizado.

Pare e aguarde minha confirmação.

7. Próxima funcionalidade

Somente após a conclusão completa da funcionalidade atual:

Analise a próxima funcionalidade pendente.
Reinicie o fluxo a partir do passo 1.
Regras Importantes
Nunca pule etapas.
Nunca faça commit sem que os testes estejam passando.
Nunca faça push sem minha aprovação explícita.
Sempre explique brevemente o que foi realizado em cada etapa.
Sempre aguarde minha validação antes de seguir para o próximo passo.
Caso encontre dúvidas ou ambiguidades, interrompa o fluxo e solicite esclarecimentos.
Priorize código limpo, manutenível e aderente aos padrões já existentes no projeto.
Antes de alterar qualquer arquivo, analise o contexto para evitar regressões.
Se identificar melhorias necessárias relacionadas à funcionalidade, apresente-as no planejamento antes de implementá-las.

Importante: Trabalhe de forma incremental. Após cada etapa concluída, apresente um resumo do que foi feito e aguarde minha autorização para continuar.
